# Bank Marketing Campaign & Conversion Analysis

## Project Overview
This project analyzes bank marketing campaign data to understand customer responses and conversion rates.

## Objectives
- Clean and prepare the marketing dataset
- Analyze customer and campaign information
- Calculate conversion rates
- Compare campaign performance
- Identify factors affecting customer conversion
- Create an interactive Power BI dashboard

## Tools Used
- Python
- Pandas
- Google Colab
- Power BI
- Excel

## Dataset
Bank Marketing Dataset from UCI Machine Learning Repository.

## Key Analysis
- Customer subscription analysis
- Conversion rate
- Conversion by job
- Conversion by contact method
- Monthly conversion
- Education-wise analysis
- Campaign performance

## Dashboard
The Power BI dashboard presents the key findings and conversion insights.

![Dashboard](https://raw.githubusercontent.com/tharshini61/bank-marketing-analysis/main/task3.png)

## Conclusion
The analysis helps identify customer segments and campaign factors associated with better conversion, which can support more effective marketing strategies.
